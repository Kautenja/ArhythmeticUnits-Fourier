\paragraph{Window menu}
\begin{center}

These are fixed shapes; there are no additional shape parameters.

\paragraph{Smooth menu}
None; 1/48, 1/24, 1/12, 1/9, 1/6, 1/5, 1/4, 1/3, 1/2, 2/3, 3/4, 1,
1.5, 2, or 2.5 octaves.

\paragraph{Color range}
Decibels: $-120$ to $+24$ dB, starting at $-90$ to 0 dB; minimum span
0.1 dB. Linear: 0--200\%, starting at 0--100\%; minimum span 0.1 percentage
point. Each scale remembers its range. Older patches without these settings
open in Linear at 0--100\%.

\paragraph{Palette menu}
Viridis, Cividis, Magma (default), Plasma, Inferno, Bone, and Gray.
